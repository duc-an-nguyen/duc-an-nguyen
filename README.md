## Selected Projects

### 1. Real-Time Multi-Camera Smart City Surveillance System

**Production Computer Vision | Multi-Task AI | GPU Optimization**

Designed and optimized **HydraNet**, a shared-backbone, multi-task computer vision architecture supporting real-time detection, tracking, segmentation, classification, and recognition across multiple camera streams.

**Key outcomes:**
- Reduced reported system resource cost by more than 50% through backbone sharing.
- Optimized inference with ONNX, TensorRT, and FP16.
- Supported 24 concurrent cameras on an NVIDIA A5000.
- Achieved approximately 5–10 FPS per camera in the deployed system.

**Stack:** Python · PyTorch · OpenCV · ONNX · TensorRT · Docker

[Read full case study →](https://ducannguyen.net/projects/aqua_smart_city.html)

### 2. Industrial Coffee Bean Sorting Machine

**Embedded Computer Vision | Industrial Automation**

Developed a computer vision pipeline for automated coffee-bean quality inspection using a global-shutter camera and embedded computing hardware.

**Key contributions:**
- Imaging-system design and controlled illumination.
- Shape- and color-based defect detection.
- Image preprocessing for non-uniform lighting.
- Runtime and memory optimization for embedded deployment.

**Stack:** C/C++ · OpenCV · NVIDIA Jetson Nano · Raspberry Pi · Linux

[Read full case study →](https://ducannguyen.net/projects/coffee_bean_sorting_machine.html)

### 3. Real-Time Object Detection on Raspberry Pi

**Edge AI | Resource-Constrained Inference**

Deployed MobileNet-SSD through OpenCV DNN on a Raspberry Pi 3, performing object detection directly on the edge device without a separate inference server.

**Key contributions:**
- On-device object detection using OpenCV DNN and Caffe.
- Concurrent camera acquisition and inference.
- Local processing with remote monitoring over LAN.

**Stack:** Python · OpenCV · Caffe · MobileNet-SSD · Raspberry Pi 3

[Read full case study →](https://ducannguyen.net/projects/raspberry_pi_object_detection.html)
